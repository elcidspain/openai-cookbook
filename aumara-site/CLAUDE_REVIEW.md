### 2. EN and ES rendering together — NOT A BUG

The page has an actual language switcher. Non-selected language blocks are hidden by CSS:

```css
[data-lang]{display:none}
html[data-language="en"] [data-lang="en"],
html[data-language="es"] [data-lang="es"]{display:block}
```

JavaScript sets `data-language` on the root element and persists the selection in `localStorage`. The text-only renderer exposed hidden DOM content, which created the false impression that both languages appear together.
