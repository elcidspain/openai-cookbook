# AUMARA domain lock

`aumara.me` and `www.aumara.me` are attached to Vercel project `aumara-path-0827`.
That project was git-linked to this repository. Every merge to `main` redeployed
EL CID Country Club (`elcid-site`) onto the AUMARA ads URL.

`ignoreCommand: exit 0` stops those git deploys.
Do not remove it. Do not route `/` to `elcid-site`.
Country Club lives on elcidspain.com only.
AUMARA lives on aumara.me only.
